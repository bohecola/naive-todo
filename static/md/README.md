# NTodo

使用 React + TS 实现的一个 TodoList，基础操作习惯参考了 Microsoft To Do

## 技术栈

- React 19 + TypeScript
- Vite + Ant Design 5 + Tailwind CSS
- SWR + react-markdown

## 功能

- [x] 任务添加、删除和修改
- [x] 设置任务优先级标签
- [x] 拖拽排序

## 数据存储

浏览器 LocalStorage

## 开发

```bash
# 安装依赖
pnpm install

# 启动开发服务器（默认 http://localhost:5173）
pnpm dev

# 类型检查 + 构建生产版本
pnpm build

# 运行测试
pnpm test
```
